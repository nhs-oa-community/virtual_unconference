# Virtual Unconference

## What is a Virtual Unconference?

An unconference is an event at which, unlike a traditional lecture format, topics are proposed by the audience, and voted for. 
The most popular are then scheduled and discussed as part of a standard format. 
The NHS-R committee used to host these sessions, mostly run by University of Edinburgh colleagues.
The Virtual Unconference is designed to recreate the format in an accessible online way.

## What's this repository for?

Before the conference, those who have registered their interest in attending will be asked to add new discussion topics as individual issues into this repository. 
Attendees can also note their enthusiasm for existing topics by giving the issue a 'thumbs up'.
The timetable for the event will be automatically created from the list of topics (issues) with the greatest number of thumbs.
